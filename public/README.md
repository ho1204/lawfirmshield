# 법률사무소 쉴드 홈페이지

참고 사이트의 신뢰감 있는 네이비·골드 분위기를 바탕으로 새롭게 구성한 반응형 홈페이지입니다. 외부 방문자는 게시판과 글을 볼 수 있고, 관리자만 로그인하여 게시판 생성·삭제 및 글 작성·삭제를 할 수 있습니다.

## 실행

별도 패키지 설치 없이 Node.js 18 이상에서 실행됩니다.

```bash
npm run dev
```

브라우저에서 `http://localhost:4173`으로 접속합니다.

## 관리자

공개 페이지에는 관리자 링크가 표시되지 않습니다. 주소 뒤에 `/admin`을 붙여 직접 접속합니다.

예: `http://localhost:4173/admin`

- 개발용 초기 비밀번호: `shield2026!`
- 실제 공개 전에는 반드시 환경변수 `ADMIN_PASSWORD`와 `SESSION_SECRET`을 설정하세요.
- 예시는 `.env.example`에 있습니다. 이 앱은 `.env` 파일을 자동으로 읽지는 않으므로 배포 서비스의 환경변수 설정 화면에서 입력하거나 실행 환경에 주입하면 됩니다.

게시판을 삭제하면 그 안의 글도 함께 삭제됩니다. 데이터는 `data/store.json`에 저장되며, 이 폴더는 첫 실행 때 자동 생성됩니다.

## 배포 전 확인

- 대표자·주소·연락처·사업자 정보 최종 확인
- 개인정보처리방침 및 상담 신청 기능 추가 여부 결정
- HTTPS가 적용되는 서버에 배포
- 운영용 비밀번호와 충분히 긴 임의의 세션 비밀키 설정
- 여러 서버로 확장한다면 JSON 대신 PostgreSQL 등 데이터베이스로 교체
